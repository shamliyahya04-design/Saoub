# Saoub — PHASE 1 Base Agent Selection

## Objective
Select eligible Base Agents objectively before any modification or integration.

## Mandatory Constraints
- Base Agents are evaluated independently and unmodified.
- No ready-made workflows are adopted as Saoub solutions.
- No integration before benchmark evidence.
- No selection based on reputation or preference alone.
- GitHub is the sole source of truth.
- No local Git repository.
- No branches.
- No secrets or credentials.

## Candidate Eligibility Gate
A candidate must:
1. Be runnable in its original form.
2. Have a compatible license.
3. Provide documented capabilities relevant to autonomous execution.
4. Have sufficient maintainability and technical activity.
5. Expose enough control/observability for objective benchmarking.
6. Not require Saoub-specific modifications before baseline evaluation.

## Evaluation Dimensions
- General task execution
- Tool use
- Browser/computer interaction
- Planning and reasoning
- Reliability
- Recovery capability
- Observability
- Extensibility
- Security boundaries
- Performance/cost
- Documentation and maintainability
- License/IP compatibility

## Evidence Rule
Every material selection claim must be supported by reproducible evidence.
No candidate is considered superior before PHASE 2 benchmark results.

## IP Boundary
Base Agent code, third-party libraries, and generic capabilities are not Saoub inventions.
Potential Saoub inventions must be recorded separately in the Invention Ledger and evaluated against prior art.

## Selection Gate
PHASE 1 may be approved only when:
- Candidates are identified and documented.
- Eligibility has been checked.
- Evaluation rubric is fixed before benchmarking.
- IP boundaries are documented.
- Benchmark inputs are protected from candidate-specific bias.
- Risks and limitations are explicitly recorded.
- Final review confirms readiness for PHASE 2.

## Exit Criteria
PHASE 1 is not complete until the above gates pass and a final audit approves transition to PHASE 2 — Baseline Benchmark.
