# Saoub — Invention Ledger

## Purpose
Record every potentially inventive technical mechanism.

## Mandatory Rules
- No invention claim without prior-art analysis.
- Base agents and tool aggregation are not inventions by themselves.
- Record technical problem, mechanism, differences, technical effect, evidence, alternatives, and limitations.
- Record date and GitHub commit for every material invention.
- No public disclosure of core inventive material before IP review.
